# Host: project guide for Claude Code

Host is an idle / roguelite game about a virus spreading from a petri dish to a whole planet.
It's Caleb's game. He plays it as a full-screen Android app on a Samsung Galaxy Fold 8
(the cover screen is short and wide-ish, so short screens matter), and sometimes in a desktop browser.

## How we work

- **The whole game is one file: `www/index.html`.** HTML, CSS and JavaScript all live in it. Edit it directly.
- **After every finished change: test, commit, push to `main`.** Pushing triggers GitHub Actions, which builds
  the APK and publishes it as a release. Caleb then installs it from the in-app "Update available" button
  or the repo's Releases page. Don't leave finished work uncommitted.
- Commit messages: short, plain, describing what changed for the player (e.g. "Slower cure on world 1").
- Talk to Caleb in plain language and explain changes in terms of what he'll see in the game.
- **Never use em dashes**, in replies or in any in-game text. Use commas, colons, periods or parentheses.
- In-game wording: plain verbs, sentence case, explain mechanics concretely ("removes a stack", not "strips").
  Every number a player sees should match what the code actually does.

### Build pipeline (GitHub Actions)
Node 22, JDK 21 (Temurin), `android-actions/setup-android@v3` with explicit
`packages: platform-tools platforms;android-36` (the action's old default "tools" package no longer exists).
Then `npm ci`, a `sed` step that stamps `__HOST_BUILD__` (run number) and `__HOST_REPO__` (owner/repo) into
`www/index.html`, `npx cap sync android`, `./gradlew assembleDebug`, and `softprops/action-gh-release`
publishes tag `build-<run_number>` with `Host.apk`. It's a debug build; that's fine for sideloading.

**Never replace the `__HOST_BUILD__` / `__HOST_REPO__` placeholders in the committed file.** The workflow
stamps them only in the build copy. The in-app update check compares the latest release tag's number against
the stamped build number, and calls the GitHub API without auth, so it only works while the repo is **public**.
In a plain browser the placeholders stay, and update checks are skipped ("Web version").

## Testing before you push

1. `node --check` on the extracted script, or just open `www/index.html` in a browser and watch the console.
2. `python tools/smoke.py` (needs `pip install playwright` and `python -m playwright install chromium`).
   It must print "page errors: none" for phone, short phone and desktop. Look at the screenshots for layout changes.
3. For balance changes: `python tools/sim.py 2` (simulated hours). Rough current baseline with the bot:
   clears world 1 on the first run in about 2.5 minutes, first run reaches about world 8, best world around
   12 to 14 after an hour and around 20 after 7 hours, first win is a long day of AFK play. The bot is a weak
   player (cheapest-first purchases), so a human should beat these numbers.

Test hooks live on `window.__host` at the bottom of the script (G, R, step, autoTick, catchUp, buyPerm,
generateWorld, hostPos, rangePx, recomputeMods, startNewRun, setSilent, ...). Keep them; the tools rely on them.

## Code map (sections are marked with `// ================= name =================` comments)

- **helpers**: fmt (number formatting), pct/signPct, seeded rng (mulberry32), shuffle.
- **static data**: zones and bosses (`ZONES`), host size types (`TYPES`), constants, run upgrades (`UP`),
  mutations (`MUT`), cards (`BOONS`, `CURSES`), permanent DNA upgrades (`PERM`), automation unlocks (`AUTO`),
  default settings, color presets.
- **state**: `G` = permanent meta save (DNA, perms, automation, settings, codex `seen`, bosses beaten, wins,
  ascension). `R` = current run (world, lifeforce, upgrade levels `lv`, mutations `mu`, boons, curses, hosts,
  phase, lives, cure, pending DNA). `M` = card modifiers recomputed from R.boons/R.curses by `recomputeMods()`.
- **canvas & geometry**: `field()` is the play area measured live between the HUD and the legend.
  `view()` maps the fixed world space to the screen. `generateWorld()` builds each world's layout.
- **derived stats**: damage, lifeforce, cleanse, adapt, regen, cure time, alert push.
- **simulation**: `step(dt)` advances one tick: stacks, damage, regen, immune cleansing, bounces, healers,
  bosses, flare, cure timer, world cleared / virus lost checks.
- **flow**: place, virusLost (+ `lostReason()`), worldCleared, victory, cards (`makeOffer`, `chooseCards`,
  `chooseStart`), runOver (banks DNA), openShop, startNewRun.
- **automation**: autoBuy, bestStart (placement styles), autoCards, `autoTick(dt)` (all timers).
- **overlays / input / panel / HUD / render / loop / save**: UI. `draw()` renders the arena on canvas.
  `catchUp(secs)` simulates offline time silently (up to 8 hours).
- **mini host renderer, guide scenes, codex**: How to play animations and the Codex reuse `drawMini()`.
- **app updates**: update check and button.
- **menus**: main menu, settings, codex, sub-screen handling (`openSub` / `closeSub`).

Phases (`R.phase`): `idle` (no run), `start` (opening card pick), `pick` (place a virus), `run`, `cards`
(after a world), `over` (with `R.stage` = `summary` then `shop`).

## Game rules as they stand

- 25 worlds in 5 zones (Petri Dish, Village, Town, City, Planet). Every 5th world is a boss world with one
  giant host in the middle that must die: Colony Prime (regrows 3x), The Herbalist (giant healer),
  The Quarantine (can't be infected until 40% of hosts are dead), The Doctor (cures nearby infections every 8s),
  Patient Omega (learns twice as fast). First kills unlock Spare virus, Second look, Hidden genome, two new boons,
  and victory + Ascension (hosts +25% health, cure 8% sooner, +35% DNA per level, up to 10).
- Each world: 3 viruses (more via perks and boons). Place one, it spreads; if it dies out you place the next.
  Dead hosts stay dead between viruses. Lose all viruses and the run ends.
- Spreading: hosts with 3+ stacks try to jump (Bounce: 15% chance every 8s base) within reach
  (0.85 x average host spacing, Reach +12%/level); every death infects the 2 nearest healthy hosts for free
  (Contagion adds more). Carriers (a trait any size can have, ~10% of hosts) jump 60% farther.
- Immune system: removes stacks, faster the longer a host is infected and as the immune alert rises with kills.
  A host that loses every stack has "fought it off" (teal ring + shield) and can't catch that virus again.
  The cure timer wipes the current virus when it lands (120s base, shrinking each world).
- Lifeforce = damage dealt; spent on run upgrades (Potency, Spread, Parasite, Evasion, Mutations).
  Upgrade costs scale up each world.
- DNA is collected during a run (kills, cleared worlds, bosses) but **only paid out when the run ends**.
  Spent in Evolve on permanent perks and automation.
- Cards: at the start of every run and after every cleared world, pick one boon and one curse.

Current tuning constants (top of the script): `worldHp = 180 * 2.6^(w-1)`, `CURE_BASE 120`, `CURE_SHRINK 1.05`,
`COST_GROWTH 2.4`, `DNA_GROWTH 1.45`, `YIELD 0.3`, cleanse `0.05 * 1.25^(w-1)`, alert push ramps from 1x in
world 1 to 3x by world 10. Change one knob at a time and re-run `tools/sim.py`.

## Design rules Caleb has set (keep these unless he changes them)

1. It's an **idle game first**, with roguelite layers on top. The AFK loop must keep going on its own.
2. **One entry point per virus.** No reseeding or second clicks while a virus is alive. Placement should matter.
3. **Slow start with real progression**, but world 1 must be beatable: it's the gentle tutorial world
   (no special hosts, no sturdy hosts, no map curses, evenly spread layout with no stragglers).
   Layout variance and difficulty grow with progress (early worlds evenly spread, clusters and gaps by world 10).
4. **Every card choice pairs one boon with one curse**, including the opening pick of a run.
5. **No single upgrade may be mandatory to win** (the virus spreads without Bounce via death spread).
6. **Card effects must be visible**: any upgrade value a card changes shows in the accent color with a dotted
   underline, and hovering/tapping it explains which card did it and the value without cards.
7. **Host layout must never depend on screen size or orientation.** Worlds live in a fixed 1.4 : 1 space and
   are scaled uniformly (and turned sideways when the play area is taller than wide). Distances must stay
   identical; never store or compute positions as fractions of the current screen.
8. **Auto-choose**: anything undecided is picked automatically after 15s when the window is focused, 5s when
   not (1s with the Reflexes perk). Picking a card yourself pauses it. Auto placement defaults to
   "Easiest targets". There's an Auto on/off button in the arena corner (red play icon when on, gray pause when off).
9. **Run end flow**: summary (6s) then the Evolve DNA screen with a 10s "Next run in Ns" countdown that the
   player can stop by tapping it; any other tap resets the countdown.
10. **Explain things in game**: host types in the legend tooltips, why a virus died (toast), fought-off markers,
    the How to play guide with animations, and the Codex.
11. **Theme**: Settings has Main color (tints the whole app: backgrounds, panels, cells, borders, tray) and
    Accent color (buttons, tabs, boons, the virus, lifeforce, health rings, highlights). Never hard-code
    purple/pink; use the CSS variables (`--main`, `--accent`, `--accent-hi`, `--stain`, `--bruise`, `--life`,
    `--tray`, `--bg`, `--slide`, `--cell`, `--membrane`, `--line`, `--panel`, `--ink`, `--muted`).
    `applyColors()` computes them, with lighter versions for dark mode.
12. **Visual style**: modern and slightly chunky but not cartoony. Corners around 6 to 12px, thin bottom
    "lift" shadows on buttons, no bouncy hover motion. Respect reduced motion (system setting or Settings).

## Layout and device notes

- Phones: arena on top, upgrade panel below (about 52% height). The bar above the panel has two buttons that
  never move: left "Hide upgrades" / "Show upgrades" (hides only the list; the overview card and tab names
  stay, tapping a tab opens it, a dot means something is affordable; saved as `G.settings.hideUpgrades`),
  right "Hide host area" / "Show host area" (the panel covers the hosts but stops below the cure countdown,
  using `--hud-bottom` set in `measureHud`). Tabs fit on one row, even at 320px.
- Very thin phones (280 to 360px): the zone path stays on one line, titles shrink slightly.
- Safe areas: backgrounds run edge to edge; content is padded with `--sat/--sab/--sal/--sar`, which take the
  larger of `env(safe-area-inset-*)` and the `--safe-area-inset-*` variables Capacitor injects on Android.
- Popups (Settings, Codex, How to play, Evolve, Strain) are sheets with a fixed header and footer and a
  scrolling middle; they must fit short screens (test at 412x560).
- The run footer is Strain (left), Evolve (center, pink dot when something is affordable), Settings (right).
  Main menu is reached from the top of Settings or with Esc.

## Gotchas

- There's a global `canvas { position: absolute; inset: 0 }` rule for the arena. Any other canvas
  (guide scenes, codex pictures) needs `position: static`.
- Many JS strings are single-quoted HTML; an apostrophe inside them breaks the script. Run `node --check`.
- Save key is `host-save-v3` in localStorage. **Never break existing saves**: add new fields with defaults in
  `load()` and `newMeta()`. One-time migrations use flags on G (example: `colorsV2`).
- `silent` mode (offline catch-up and the simulator) must skip all DOM work and floats.
- Hidden tabs pause requestAnimationFrame; returning triggers `catchUp()`.
- The Android WebView reports the camera cutout as a top inset even in immersive mode.
